[PRJ-0321] 텔레그램 미니앱·봇 유료 기능(Stars 결제) 판매

텔레그램 봇/미니앱에 프리미엄 기능을 붙이고 텔레그램 Stars로 디지털 상품·구독을 판매. 근거(추정): 텔레그램이 Stars를 디지털 상품 결제 수단으로 공식 제공 중이라 별도 결제사 계약 없이 판매 가능, 실제 수익 규모는 확인 못함. 무자본 이유: 봇 생성 무료, Cloudflare Workers 무료 티어로 호스팅. 출처: https://core.telegram.org/api/stars , https://www.theblock.co/post/298954/telegram-launches-digital-mini-app-payment-system-telegram-stars 설계 문서: https://docs.google.com/document/d/1DoIB7fhQx0KUQLHib1fVm-pGIkBpkRI8MOJcI-JqOHA/edit
